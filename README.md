# Copernicus

A personal lab on Copernicus Sentinel imagery (Copernicus Data Space Ecosystem):
maps and images, and detection of mimosa bloom on the Riviera, larch senescence in
the Southern Alps, and burned areas after forest fires.

```bash
uv sync
cp .env.example .env   # then fill in the CDSE OAuth client
uv run copernicus --help
```

Context, access paths and commands: `CLAUDE.md`. Surveys: `docs/research/`.
